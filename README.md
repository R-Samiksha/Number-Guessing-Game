
# Number Guessing Game

## About the Project
This is my first beginner-level Python project.

In this game, the computer randomly selects
a number between 1 and 100.

The player has to guess the correct number.

## Features
- Random number generation
- User input
- Too High and Too Low hints
- Counts the number of attempts
- Displays a winning message

## Technology Used
- Python

## How to Run
1. Install Python.
2. Download the project.
3. Open the project folder in VS Code.
4. Run guessing_game.py.
